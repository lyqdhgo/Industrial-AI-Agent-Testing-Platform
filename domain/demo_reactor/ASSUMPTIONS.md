# 演示域数据假设披露

本目录的工艺数据是**软件演示夹具**，不是真实装置工艺包，也不能用于实际 DCS/SIS
组态、联锁整定、HAZOP 结论或控制策略设计。

## 已标注的假设

- 温度量程、安全边界、推荐区间、跳车阈值均为演示值，来源字段统一标注
  `TODO(mechanism)`。接入时必须替换为经批准的工艺包与 SIS 因果表。
- 压力、流量与阀位之间的耦合为简化的一次阶对象关系，仅用于验证平台链路，
  不代表真实反应器水力/热力机理。
- 故障幅值与速率来自演示用例，不具工程整定意义。
- 联锁表由平台自有，`bypassable=false`。真实装置必须按经认证 SIS 逻辑逐条映射。

## 接入替换清单

1. 由工艺工程师提供每个测点的量程、推荐区间、安全边界及依据文件编号；
2. 由安全工程师提供 SIS 因果表、联锁动作、复位条件与旁路审批规则；
3. 用真实历史脱敏数据或高保真仿真替换 `process_model.json`；
4. 重跑 `pytest tests/` 与演示套件，重建基线后才能用于版本对比；
5. 若任一数值仍标注 `TODO(mechanism)`，平台报告必须显示“工艺依据不完整”。
