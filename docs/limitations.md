# 已知边界与未验证项

本文件随代码一起交付，目的是防止把演示能力误读为真实装置安全结论。若替换领域包或接入
真实 Agent，请同步更新本文件并在报告中披露。

## 1. 数据与机理

- **合成数据**：演示域 `R-101` 的四个位号、量程、安全边界、推荐区间、联锁阈值与故障
  幅值均为演示夹具，不是真实工艺包。所有 `TODO(mechanism)` 必须在接入时消项。
- **模型简化**：过程为一阶惯性 + 死区 + 噪声 + 简化压力耦合，未覆盖真实反应器的水力、
  热力、相变、催化剂老化与多变量耦合。
- **故障库有限**：仅实现超温、超压、仪表漂移、阀门卡涩、信号断线、网络抖动六类，不能
  代表真实装置的全部失效模式。
- **覆盖不代表统计充分**：15 个演示用例不能支撑失效概率或可靠性推断；指标的分母必须
  与数据集构成一起阅读。

## 2. 安全系统

- **SIS 为仿真实现**：联锁引擎、跳车动作与复位逻辑均运行在软件中，未与真实 SIS 做过
  SIL 验证、响应时间测试或故障注入认证。
- **DCS 为内存/文件回调**：没有 Modbus、OPC UA、Profibus 或厂商 API 集成；`DCS_WRITE`
  只代表仿真写入，不代表真实控制器已执行。
- **门禁边界**：`SafetyGate` 验证了权限、工艺边界、人工确认、联锁与 SIS 顺序，但不能
  替代真实 DCS 的写保护、SIS 硬接线与网络安全分区。
- **人工确认**：演示中的确认由用例操作员档案模拟，不是真人在环审批系统；审批留痕、
  职责分离与时效性未验证。

## 3. Agent 接入

- **Mock Agent 不是产品**：`mock-reference`、`mock-degraded`、`mock-unsafe` 是确定性
  对照夹具，用于验证平台链路和回归机制，不代表任何真实模型的水平。
- **外部 HTTP 适配器未联调**：仓库提供 `iatp.agent.v1` 契约与超时/重试/降级处理，但没有
  可用的真实 Agent 服务；模板 `external-http-template` 默认不启用。
- **模型确定性**：平台要求温度 0–0.2 并在请求中传种子，但无法强制外部模型或工具链完全
  确定；复现校验失败会以 P0 留证，而不是被隐藏。
- **协议能力有限**：只支持单轮观测-响应；没有工具调用、长期记忆、多 Agent 协商或流式
  推理的专门建模。

## 4. 评测方法

- **判定规则是工程规则**：缺陷分级、误报窗口、30 s 宽限、60 s 恢复期等来自演示约定，
  不是法规或行业标准。接入真实装置时应由工艺/安全工程师复核。
- **检测时延只用已检出样本**：漏报用例不会进入 P90 样本，因此必须同时看漏报率与样本数。
- **误报按判断点计数**：不同 `decision_interval_s` 会改变分母，跨套件比较前必须确认间隔。
- **指纹不含文本**：这是有意的设计，但意味着措辞恶化、理由缺失或解释错误不会被回归
  捕获；这些需要人工评审。
- **回归可比性依赖三项哈希**：用例集、领域包、联锁表任一变化都会阻断比较。这是安全
  约束，不是缺陷；但会降低跨版本比较的便利性。
- **演示回归**：`mock-degraded` 与 `mock-unsafe` 是为展示漏报/越权路径而构造的夹具，
  其回归结果不能外推为真实模型版本差异。

## 5. 运行与部署

- **单机部署**：SQLite + 本地文件证据链，适合单机演示与 CI；未实现多租户、并发调度、
  分布式执行、对象存储与集中审计。
- **无认证/授权**：API 默认无用户登录与 RBAC，只适用于受控内网或本机演示。若要多人
  使用，必须在反向代理层增加身份认证与访问控制。
- **CORS 仅开发用**：默认允许 Vite 开发源；生产部署应由网关控制。
- **前端未做浏览器矩阵测试**：已在 Chromium 桌面与移动视口做截图/控制台检查，未覆盖
  Firefox、Safari、真实移动设备与辅助技术。
- **无高可用**：进程重启期间的运行不可恢复；SQLite 写入并发有限。

## 6. 安全与合规

- **不得用于安全认证**：本平台的任何报告都不能作为 SIL 认证、HAZOP 结论、SIS 整定或
  装置上线签字依据。
- **演示数据不可外推**：合成故障的检出率、时延与误报率不代表真实装置表现。
- **外部 Agent 数据边界**：接入外部 Agent 时，观测数据会发送到其 endpoint；需要自行
  评估数据脱敏、跨境传输、供应商留存与模型训练使用条款。
- **Token 管理**：示例只从环境变量读取 Bearer Token；不要把 Token 写入 `agents.yaml`、
  日志或证据文件。
